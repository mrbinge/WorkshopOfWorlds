# Мастерская миров

Инструмент для управления большими историями (книги, манга и что угодно ещё): персонажи, связи между ними, визуальный конструктор сцен, таймлайн и лор. Работает полностью в браузере, без сервера — все данные хранятся локально на вашем устройстве (`localStorage`).

## Что в архиве

- `index.html` — сам инструмент (открывается в любом браузере)
- `manifest.json` — файл для установки как приложения на телефон
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon.png` — иконки

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на [github.com](https://github.com/new) (можно приватный).
2. Загрузите в него **все файлы из этого архива** — прямо в корень репозитория (кнопка «Add file → Upload files»).
3. Зайдите в **Settings → Pages**.
4. В разделе «Build and deployment» выберите **Source: Deploy from a branch**, ветку `main`, папку `/ (root)`. Сохраните.
5. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<ваш-логин>.github.io/<название-репозитория>/`

## Как установить на телефон как приложение

**iPhone / iPad (Safari):**
1. Откройте адрес сайта в Safari.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран «Домой»»**.
4. Готово — на экране появится иконка книги, открывается как отдельное приложение.

**Android (Chrome):**
1. Откройте адрес сайта в Chrome.
2. Нажмите меню (три точки) в правом верхнем углу.
3. Выберите **«Добавить на главный экран»** или **«Установить приложение»**.
4. Готово.

## Важно про данные

Все персонажи, сцены, связи и лор хранятся **в браузере на конкретном устройстве** (localStorage), а не на сервере и не в самом файле. Это значит:

- Данные не синхронизируются автоматически между телефоном, ноутбуком и т.д. — каждое устройство хранит свою копию.
- Если очистить данные браузера/сайта, записи пропадут.

Поэтому в инструменте есть кнопка **«Данные» → «Скачать бэкап»** — она сохраняет весь архив в один JSON-файл. Рекомендуется:
- скачивать бэкап регулярно;
- использовать кнопку **«Восстановить из файла»**, чтобы перенести данные на другое устройство или браузер.

## Обновление сайта в будущем

Если Claude (или вы сами) поменяет `index.html`, просто загрузите новую версию файла в тот же репозиторий поверх старой — GitHub Pages обновится автоматически, а сами данные пользователей (в localStorage) это не затронет.
